## نبذة عن المشروع

**إتحادات** هو الموقع الرسمي لمؤسسة لؤلؤة الاتحادات لإدارة الأملاك.  
نقدّم إدارة اتحادات الملاك، تشغيل المرافق، والإدارة المالية للمجمعات والعقارات الاستثمارية.

## تشغيل المشروع محلياً

المشروع عبارة عن موقع ثابت (Static Website)، لا يحتاج إلى أي تثبيت.

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/<username>/mollak.git
   cd mollak
   ```

2. **فتح الموقع:**
   - افتح ملف `index.html` مباشرة في المتصفح، أو
   - استخدم أي خادم محلي بسيط مثل:
     ```bash
     python -m http.server 8000
     ```
     ثم افتح `http://localhost:8000`
